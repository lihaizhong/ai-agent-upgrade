# 机器学习基础

机器学习（Machine Learning, ML）是人工智能的一个分支，它使计算机能够从数据中学习并做出预测或决策，而无需进行明确的编程。

## 主要类型

机器学习可以分为三种主要类型：

### 监督学习（Supervised Learning）

监督学习使用带有标签的数据来训练模型。模型学习输入与输出之间的映射关系，然后可以对新的未标记数据进行预测。

常见算法包括：
- 线性回归（Linear Regression）
- 逻辑回归（Logistic Regression）
- 支持向量机（SVM）
- 决策树和随机森林
- 神经网络

应用场景：房价预测、邮件分类、图像识别、医疗诊断等。

### 无监督学习（Unsupervised Learning）

无监督学习处理没有标签的数据，目标是发现数据中的隐藏模式或结构。

常见算法包括：
- K-Means 聚类
- 层次聚类
- 主成分分析（PCA）
- 自编码器（Autoencoder）
- t-SNE 降维

应用场景：客户分群、异常检测、降维可视化、推荐系统等。

### 强化学习（Reinforcement Learning）

强化学习通过与环境交互来学习最优策略。智能体（Agent）执行动作并获得奖励或惩罚，目标是最大化长期累积奖励。

关键概念：
- 智能体（Agent）
- 环境（Environment）
- 状态（State）
- 动作（Action）
- 奖励（Reward）
- 策略（Policy）
- 价值函数（Value Function）

应用场景：游戏 AI（如 AlphaGo）、机器人控制、自动驾驶、资源调度等。

## 模型评估

评估机器学习模型的常用指标：

**分类任务**：
- 准确率（Accuracy）
- 精确率（Precision）
- 召回率（Recall）
- F1 分数
- ROC 曲线和 AUC
- 混淆矩阵

**回归任务**：
- 均方误差（MSE）
- 均方根误差（RMSE）
- 平均绝对误差（MAE）
- R² 决定系数

## 过拟合与欠拟合

- **过拟合（Overfitting）**：模型在训练数据上表现很好，但在新数据上表现差。通常由模型过于复杂或训练数据不足引起。
- **欠拟合（Underfitting）**：模型在训练数据和新数据上都表现不佳。通常由模型过于简单引起。

解决方法：正则化、交叉验证、增加数据量、特征工程、调整模型复杂度等。

## 数据预处理

机器学习项目中，数据预处理通常占用 70% 以上的时间。关键步骤包括：

1. 数据清洗：处理缺失值、异常值、重复数据
2. 特征工程：特征选择、特征提取、特征构造
3. 数据转换：标准化（Standardization）、归一化（Normalization）
4. 编码：One-Hot 编码、Label 编码
5. 数据划分：训练集、验证集、测试集

## 深度学习简介

深度学习是机器学习的一个子领域，使用多层神经网络（深度神经网络）来学习数据的层次化表示。

主要架构：
- 卷积神经网络（CNN）：擅长图像处理
- 循环神经网络（RNN）：擅长序列数据
- Transformer：自注意力机制，成为现代 NLP 的基础
- 生成对抗网络（GAN）：用于生成式任务

深度学习成功的关键因素：
- 大量数据
- 强大的计算资源（GPU/TPU）
- 更好的优化算法
- 正则化和归一化技术

## 实践建议

1. 从简单模型开始，逐步增加复杂度
2. 重视数据质量，好的数据胜过复杂模型
3. 始终使用交叉验证和独立的测试集
4. 记录实验过程和结果，便于复现
5. 关注模型的可解释性，特别是在关键应用场景中
6. 持续学习，跟进最新研究进展
